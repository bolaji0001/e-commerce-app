# My Store: E-Commerce App

[LIVE](https://e-commerce-app-three-pink.vercel.app/)

Full-stack store built with React, TypeScript, Node/Express, PostgreSQL and Stripe.

## Stack

React · TypeScript · Tailwind · Express · PostgreSQL · Stripe · Jest · Playwright

## Note

Render’s free tier sleeps when idle, so the first request can take about a minute. Open the API URL once to wake it

## Run locally

1. `docker compose up -d`
2. `cd apps/api && npm install && npm run dev`
3. `cd apps/web && npm install && npm run dev`
